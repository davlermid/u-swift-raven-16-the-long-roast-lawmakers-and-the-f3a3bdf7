One satirical sentence roasting lawmakers who regulate AI, crypto or the
internet but cannot convert a file to PDF. `main.ts` writes the entry to
`/output/entry.txt` (UTF-8, single sentence, no trailing newline).

> Congress can ban an algorithm overnight but can't turn the bill banning it into a PDF.
